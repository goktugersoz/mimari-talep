⚠️ Supabase Taslak Projeler Bağlantı Hatası

Taslak projelerin çalışabilmesi için veritabanında gerekli tanımlamalar eksik görünüyor. Lütfen Supabase SQL Editor panelinizde aşağıdaki kodların tamamını kopyalayıp çalıştırın:

-- 1. Tabloyu oluşturun (eğer yoksa)
create table if not exists draft_projects (
  id text primary key,
  created_at timestamptz default now(),
  file_name text,
  file_url text,
  file_size numeric,
  crm_requested boolean default false,
  takim_requested boolean default false,
  sayim_requested boolean default false,
  uploaded_by text,
  status text default 'mevcut'
);

-- 2. Erişim yetkilerini verin ve RLS'i devre dışı bırakın
grant all privileges on table draft_projects to anon;
grant all privileges on table draft_projects to authenticated;
grant all privileges on table draft_projects to service_role;
alter table draft_projects disable row level security;

-- 3. Önbelleği yenilemeye zorlayın
comment on table draft_projects is 'Draft Projects Table';

Çizilen taslak DWG dosyalarını buradan yükleyebilir, AutoCAD ile doğrudan açıp düzenleyebilir ve yanlarındaki CRM, TAKIM ve SAYIM kutucuklarını işaretleyerek talepleri yönetebilirsiniz.

📐 AutoCAD Otomatik Senkronizasyon Rehberi

🎯 Amaç: Taslak dosyasına tıkladığınızda AutoCAD doğrudan açılsın ve çizimi tamamlayıp Ctrl+S ile kaydettiğinizde dosya sisteme otomatik olarak aktarılsın.

YÖNTEM 1: Tam Otomatik Köprü (Tavsiye Edilen)

  1. Uygulama klasöründeki autocad_koprusu.bat dosyasına çift tıklayarak çalıştırın.
  2. Yukarıdaki köprü çubuğu yeşil (Aktif) duruma gelecektir.
  3. Taslak tablosunda 📐 AutoCAD ile Aç butonuna veya dosya adına tıkladığınızda çizim doğrudan AutoCAD'de açılır.
  4. AutoCAD'de Ctrl+S (Kaydet) tuşuna bastığınız an, çizim arka planda sisteme otomatik yüklenir!

YÖNTEM 2: Köprüsüz Hızlı Güncelleme (Her Zaman Çalışır)

  1. Köprü çalışmıyorsa dosya adına tıkladığınızda DWG bilgisayarınıza iner ve AutoCAD ile açabilirsiniz.
  2. Çizimi AutoCAD'de kaydedin.
  3. Ardından ilgili taslağın yanındaki 🔄 DWG Güncelle butonuna basıp kaydettiğiniz dosyayı seçin, VEYA dosyayı doğrudan ilgili tablodaki satırın üzerine sürükleyip bırakın!
  4. Dosya anında sisteme kaydedilir ve versiyon yenilenir.

Sisteme giriş yapabilecek yeni kullanıcılar oluşturabilir, şifre belirleyebilir ve yetkilerini yönetebilirsiniz.
