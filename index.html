⚠️ Supabase Taslak Projeler Bağlantı Hatası

Taslak projelerin çalışabilmesi için veritabanında gerekli tanımlamalar eksik görünüyor. Lütfen Supabase SQL Editor panelinizde aşağıdaki kodların tamamını kopyalayıp çalıştırın:

-- 1. Tabloyu oluşturun (eğer yoksa)
create table if not exists draft_projects (
  id text primary key,
  created_at timestamptz default now(),
  file_name text,
  file_url text,
  file_size numeric,
  crm_requested boolean default false,
  takim_requested boolean default false,
  sayim_requested boolean default false,
  uploaded_by text,
  status text default 'mevcut'
);

-- 2. Erişim yetkilerini verin ve RLS'i devre dışı bırakın
grant all privileges on table draft_projects to anon;
grant all privileges on table draft_projects to authenticated;
grant all privileges on table draft_projects to service_role;
alter table draft_projects disable row level security;

-- 3. Önbelleği yenilemeye zorlayın
comment on table draft_projects is 'Draft Projects Table';
